# Viborita

## Descripción del proyecto

Viborita es un videojuego desarrollado en consola utilizando C#. El jugador controla una serpiente que debe desplazarse por el tablero recolectando comida para aumentar su tamaño y obtener puntos.

El objetivo principal es alcanzar 10 puntos evitando colisiones con los bordes del mapa o con el propio cuerpo de la serpiente.

---

# Características implementadas

- Movimiento en tiempo real mediante teclado.
- Sistema de generación aleatoria de comida.
- Incremento dinámico del tamaño de la viborita.
- Contador de puntos.
- Detección de colisiones.
- Interfaz visual en consola.
- Diseño visual utilizando caracteres ASCII y colores.
- Menú principal para navegación entre juegos.
- Organización modular mediante múltiples clases.

# Mecánica del juego

## Controles

- Flechas del teclado → mover la viborita.
- `Q` → salir del juego.

---

## Reglas

- La viborita se mueve constantemente por el tablero.
- Al consumir comida (`*`) aumenta el puntaje.
- Cada punto hace crecer el tamaño de la serpiente.
- El juego finaliza si:
  - la viborita choca con los bordes.
  - la viborita colisiona consigo misma.
- El jugador gana al alcanzar 10 puntos.
